# Website UMKM Kopi Kita ☕

Website sederhana untuk UMKM **Kopi Kita**, dirancang sebagai *landing page* interaktif untuk memperkenalkan menu, profil usaha, dan memudahkan pemesanan via WhatsApp.

---

## 📁 Struktur Repositori

```text
WEB_UMKM_MINUMAN/
│
├── index.html               # File utama HTML (Landing Page)
├── style.css                # File styling CSS
├── README.md                # Dokumentasi repositori
│
├── dokumen/
│   ├── ARSITEKTUR_WEBSITE.md # Dokumen Arsitektur & Diagram
│   └── USER_STORY.md         # Dokumen User Story & Acceptance Criteria
│
└── images/                  # Folder aset gambar (belum dilampirkan)

🚀 Fitur Website
Header & Navigation Bar: Navigasi cepat ke setiap bagian halaman.

Hero Section: Area promosi utama dengan tombol pemesanan.

Daftar Menu Favorit: Tampilan produk beserta harga dan deskripsi.

Tentang Kami: Informasi profil UMKM Kopi Kita.

Kontak & Lokasi: Informasi jam buka dan tombol pemesanan otomatis via WhatsApp.

Tampilan Responsif: Nyaman diakses melalui smartphone maupun laptop.

🛠️ Teknologi yang Digunakan
HTML5 & CSS3
